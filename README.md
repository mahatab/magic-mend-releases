# Magic Mend releases

Signed installers for **Magic Mend**, a small tray app that rewrites the text you select, using your own Claude or ChatGPT login.

Download the latest version from [Releases](https://github.com/mahatab/magic-mend-releases/releases/latest).

| Platform | Signing |
| --- | --- |
| Windows (x64) | Signed with Azure Artifact Signing (Mahatab Ur Rashid) |
| macOS (universal) | Signed with a Developer ID and notarized by Apple |

Each installer stays at the same versioned link forever, for example
`https://github.com/mahatab/magic-mend-releases/releases/download/v1.1.2/Magic.Mend_1.1.2_x64-setup.exe`.

Silent install on Windows: `"Magic.Mend_1.1.2_x64-setup.exe" /S`

Magic Mend needs the Claude Code CLI or the ChatGPT Codex CLI, signed in with your own subscription.
